A set of two-state buttons that can be toggled on or off.

<Preview src="toggle-group?style=primary">

```dart
ShadToggleGroup<String>.multiple(
  onChanged: (values) => print(values),
  items: const [
    ShadToggleGroupItem(value: 'bold', child: Icon(LucideIcons.bold)),
    ShadToggleGroupItem(value: 'italic', child: Icon(LucideIcons.italic)),
    ShadToggleGroupItem(
      value: 'underline',
      child: Icon(LucideIcons.underline),
    ),
  ],
)
```

</Preview>

## Single

At most one item can be pressed. Set `allowDeselection: false` to always keep one item pressed.

<Preview src="toggle-group?style=single">

```dart
ShadToggleGroup<String>(
  initialValue: 'center',
  onChanged: (value) => print(value),
  items: const [
    ShadToggleGroupItem(
      value: 'left',
      child: Icon(LucideIcons.textAlignStart),
    ),
    ShadToggleGroupItem(
      value: 'center',
      child: Icon(LucideIcons.textAlignCenter),
    ),
    ShadToggleGroupItem(
      value: 'right',
      child: Icon(LucideIcons.textAlignEnd),
    ),
  ],
)
```

</Preview>
